# 밑글(MITGEUL) 개인정보 처리방침

시행일: 2026년 11월 19일 (앱 버전 0.1.0)

「개인정보 보호법」 제30조에 따라 밑글(MITGEUL, 생활기록부 초안 작성 도우미, 이하 "앱")이 다루는 개인정보와 그 처리 방법을 다음과 같이 공개합니다.

## 제1조(총칙과 데이터 처리 구조)

앱은 교사가 자기 Windows PC에서 실행하는 프로그램(Electron 기반)이며, 이용자는 교사입니다.

- 앱 제작자(이하 "제작자")는 서버를 운영하지 않으며, 앱이 다루는 정보를 받거나 보관하지 않습니다.
- 학생 정보와 작성 내용은 교사의 PC에만 암호화해 저장합니다.
- 교사가 AI 기능을 실행할 때에만, 학생 이름을 임시 표식으로 바꾼 본문을 교사가 고른 AI 제공자 한 곳으로 보냅니다.
- 학생 정보의 개인정보처리자는 학교이며, 교사는 학교 업무를 위한 보조 도구로 앱을 사용합니다.
- 사용 통계 수집, 광고, 분석 도구, 자동 업데이트 기능은 없습니다.

## 제2조(처리하는 개인정보 항목)

교사가 직접 입력하거나 파일에서 불러온 다음 항목만 처리합니다.

- 학생 정보: 이름, 교사가 등록한 별칭, 학년·반·번호, 학교급·학년도·교육과정
- 작성 정보: 관찰 기록, 참여한 행사·활동과 역할, AI 후보 문장, 초안, 최종 본문, 검토 기록
- 교사 설정: 학교급·학년도, 학급·과목·동아리 구성, 기재 금지 문구, 사용할 AI 제공자와 모델
- AI 제공자 API 키(Gemini): 교사가 발급받아 입력한 키
- 구독 CLI(Claude·ChatGPT): 교사가 PC에 설치한 Claude Code·Codex를 실행합니다. 로그인은 앱의 [Claude 로그인]·[ChatGPT 로그인] 버튼이 각 CLI의 로그인 기능을 실행해 교사가 브라우저에서 직접 하며, 로그인 정보는 각 CLI가 보관하고 이 앱은 읽거나 보관하지 않습니다. 앱은 로그인 화면 주소와 ChatGPT 기기 코드만 화면에 보여 주고, Claude 로그인 코드는 교사가 붙여 넣은 값을 Claude Code에 그대로 넘깁니다.
- 앱 잠금 비밀번호: 사용하는 경우에만 쓰며, 비밀번호 자체는 저장하지 않고 저장 자료를 여는 키를 만드는 데에만 씁니다.

주민등록번호, 연락처, 주소, 성적, 건강 정보는 입력받지 않습니다. 관찰 기록에도 이런 내용을 적지 마세요.

## 제3조(처리 목적)

- 학생 정보와 작성 정보: 학교생활기록부 문장 초안 작성, 교사 검토, 파일 출력
- 교사 설정: 학교급·학년별 기재 기준 적용과 기재 금지 문구 검사
- API 키·구독 CLI: 교사가 고른 AI 제공자에 교사 본인 명의로 요청(Gemini는 API 키, Claude·ChatGPT는 구독 CLI)
- 앱 잠금 비밀번호: 저장 자료 보호

위 목적에 필요한 최소한의 정보만 처리합니다.

## 제4조(보유 기간과 파기)

- 앱 자료: 교사가 지울 때까지 교사 PC의 %APPDATA%\MITGEUL 폴더에 보관합니다. 기본설정 > 정보의 [전체 자료 삭제]로 학생·기록·저장 키를 지우면 복구할 수 없습니다.
- API 키(Gemini): 업무 자료와 따로 보관하므로 [전체 자료 삭제]로는 지워지지 않습니다. 기본설정 > AI 연결에서 [삭제]를 눌러 지워 주세요. 학교 공용 PC라면 사용 후 바로 지우는 것을 권합니다.
- CLI 로그인 정보: 각 CLI가 사용자 폴더(Claude Code는 .claude, Codex는 .codex)에 보관하며 이 앱의 [전체 자료 삭제]로는 지워지지 않습니다. 학교 공용 PC라면 사용 후 기본설정 > AI 연결의 [로그아웃](또는 터미널에서 claude auth logout, codex logout 명령)으로 로그아웃해 주세요.
- 자동 백업: 문서 폴더의 "밑글 백업"에 하루 1개씩 남기고 14일이 지나면 자동으로 지웁니다.
- 이동용 백업과 출력 파일(XLSX·HWPX): 교사가 지울 때까지 남습니다. 학교 지침에 따라 보관하고 파기해 주세요.
- AI 제공자로 보낸 내용: 제6조의 각 제공자 정책에 따릅니다.
- 앱을 더 쓰지 않으면 실행 파일과 위 폴더·파일을 모두 지워 주세요.

## 제5조(제3자 제공)

제작자는 개인정보를 받지 않으므로 제3자에게 제공하지 않습니다.

## 제6조(업무위탁과 국외 이전)

제작자는 개인정보 처리를 위탁하지 않습니다. 다만 교사가 AI 기능을 실행하면 교사가 고른 아래 제공자 한 곳으로 본문이 국외 전송됩니다. 전송은 Gemini는 교사 본인의 API 키로, Claude·ChatGPT는 교사 PC에 설치된 구독 CLI가 교사 본인의 구독 계정으로 하며, 제공자와의 이용 계약은 교사(학교)와 제공자 사이에 맺어집니다.

- 이전받는 자와 국가: Google LLC(Gemini API, 미국), Anthropic PBC(Claude Code, 미국), OpenAI(Codex, 미국) 중 교사가 고른 한 곳
- 이전 시기와 방법: 교사가 AI 후보 생성·윤문·분량 조정을 실행할 때, 암호화된 통신(HTTPS)으로 전송(Claude·ChatGPT는 구독 CLI가 전송)
- 이전 항목: 해당 학생의 관찰 기록, 고른 관찰 항목과 행사·활동, 초안 문장, 학교급과 영역, 기재 금지 문구, 작성 지시문. 명단에 있는 학생의 성명 전체와 등록한 별칭은 [[학생A]] 같은 임시 표식으로 바꾸며, 이름이 남아 있으면 전송을 막습니다.
- 이용 목적: 문장 후보 생성과 다듬기
- 보유·이용 기간: 각 제공자의 약관과 개인정보처리방침에 따릅니다.
- 거부 방법: AI 기능을 쓰지 않으면 전송되지 않으며, 관찰 기록과 최종 본문을 교사가 직접 작성할 수 있습니다.

성을 뺀 이름만 적은 경우는 일반 단어와 겹쳐 바꾸지 않으므로, 관찰 기록에는 성명 전체나 등록한 별칭을 쓰세요. 무료 이용 등급 등 일부 조건에서는 제공자가 입력 내용을 서비스 개선에 쓸 수 있으니, 사용 전에 제공자의 약관과 학교의 개인정보 보호 지침을 확인해 주세요. API 키 확인과 모델 목록 조회(Gemini)는 학생 정보 없이 키만으로 보냅니다. 구독 CLI는 앱이 넘긴 문안 외에 CLI 자체 지시와 계정·환경 정보(예: Claude Code는 계정 이메일, 작업 폴더·OS·날짜, Codex는 교사 PC에 설치된 Codex 스킬 이름)를 함께 보내며, 이 부분은 앱이 확인하거나 막을 수 없습니다. 앱은 CLI를 빈 임시 폴더에서 도구·사용자 설정·MCP·세션 저장 없이 실행하고, Codex에는 글쓰기에 필요 없는 도구·스킬 설명을 빼도록 설정해 이런 정보를 줄입니다. 상태 확인과 모델 연결 시험은 학생 정보 없이 실행합니다.

## 제7조(정보주체의 권리와 행사 방법)

- 앱 자료는 교사의 PC에만 있어 제작자는 열람·정정·삭제할 수 없습니다.
- 교사는 앱에서 학생 정보와 작성 내용을 바로 열람·수정·삭제할 수 있습니다.
- 학생과 보호자의 열람·정정·삭제·처리정지 요구는 학교의 개인정보 처리 절차에 따라 학교와 담당 교사에게 하실 수 있습니다.

## 제8조(만 14세 미만 아동의 개인정보)

앱은 교사만 사용하며, 학생이 직접 가입하거나 이용하지 않습니다. 학생 정보는 교사 PC에만 저장하고 제작자에게 보내지 않으며, AI 제공자로 보낼 때는 이름을 임시 표식으로 바꿉니다.

## 제9조(안전성 확보 조치)

- 저장 암호화: 앱 자료와 백업을 AES-256-GCM으로 암호화하고, 암호화 키는 Windows 계정 보호 기능 또는 앱 잠금 비밀번호로 보호합니다.
- 키 분리: Gemini API 키는 업무 자료·백업과 분리해 Windows 계정 보호 기능으로 암호화하며 백업에 넣지 않습니다. CLI 로그인 정보는 앱이 읽거나 보관하지 않습니다.
- 전송 통제: Gemini 요청은 정해 둔 제공자 주소로만 HTTPS로 보내고 API 키는 주소에 넣지 않습니다. Claude·ChatGPT 요청은 교사가 고른 구독 CLI로만 보냅니다. 어느 쪽이든 전송(실행) 직전에 확인한 문안과 같은지와 이름이 남았는지 검사합니다.
- 화면 통제: 앱 화면은 외부 접속을 막고(콘텐츠 보안 정책), 정해 둔 안내 링크만 기본 브라우저로 엽니다.
- 교사 PC 관리: Windows 계정 암호와 화면 잠금을 사용하고, 출력 파일은 학교 지침에 따라 관리해 주세요.

## 제9조의2(자동 수집 장치의 설치·운영과 거부)

앱은 이용자를 식별하거나 이용 기록을 수집하기 위한 쿠키, 웹 비콘 등 자동 수집 장치를 설치·운영하지 않습니다. 따라서 따로 거부 설정을 할 필요가 없습니다.

앱을 내려받는 안내 웹 페이지도 쿠키나 방문 분석 도구를 쓰지 않습니다. 다만 글꼴을 Google Fonts에서 불러오므로 페이지를 열면 브라우저가 Google 서버에 접속하며, 페이지를 올린 호스팅 업체가 일반적인 접속 기록(IP 주소, 접속 시각 등)을 남길 수 있습니다.
